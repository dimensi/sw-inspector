Cooperative Messages fixture


After explicit registration, use Inspector Messages and type one of these JSON values yourself. Check Request reply on supplied port for echo/delayed/no-reply. Start listening explicitly for page-directed messages. Nothing sends on page load.


  • {"fixture":"echo","value":"hello"} replies on the supplied port.
  • {"fixture":"delayed-reply","value":"hello"} replies after one second.
  • {"fixture":"no-reply"} does not reply; Inspector reports its five-second timeout without assuming delivery failure.
  • {"fixture":"page-directed","value":"hello"} sends one ordinary message to this source page; it is not correlated with a request.
